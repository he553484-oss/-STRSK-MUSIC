# STRSK MUSIC 3.0

Proyecto de un reproductor musical SwiftUI para iPhone 15 Pro, iOS 26 o posterior y AltStore Classic. El diseño combina importación local, letras sincronizadas y descubrimiento musical mediante YouTube Data API v3.

M1 y M2 completados. Luma es la base elegida, en `7006a4b51aa3bc5a1175036ea7ec83034fdccbfe`. Su proyecto Xcode original se mantiene en un checkout separado. M3 se intentó en Linux y espera un resultado de Xcode. El fork STRSK, la integración y la IPA quedan pendientes de ese resultado. [Proyecto original fijado](https://github.com/knp-org/luma-ios/tree/7006a4b51aa3bc5a1175036ea7ec83034fdccbfe/Luma.xcodeproj).
